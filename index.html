2Modules

MOD-01Instrument

seqbaby

A step sequencer and drum machine in the browser. Per-track synthesis, filters, envelopes, and pattern chaining, with song and patch sharing plus collaborative editing.

Next.js · Web Audio API Play ↗ Source ↗
MOD-02WordPress plugin

Loop Builder

A visual query loop for the block editor. Build a post query by taxonomy, meta, date, or author, then design the item card with native blocks. Server-rendered, with a live preview in the editor.

PHP · Block editor · Open source Source ↗
MOD-03WordPress plugin

Email Interceptor Router

Hooks wp_mail and rewrites the recipient list before mail leaves the site — replace addresses, route by subject pattern, or block recipients. Keeps staging mail off real inboxes and sends notifications to the right team.

PHP · wp_mail · Open source Source ↗
MOD-04WooCommerce plugin

WC Pricebook

Role-based pricing and catalog visibility for WooCommerce — tiers mapped to WordPress roles, per-product overrides, quantity breaks, and negotiated per-customer prices. All configuration, no code.

PHP · WooCommerce · Open source Docs ↗ Source ↗
MOD-05WooCommerce plugin

Order Audit Log

Writes an attributed order note for every change — items, prices, coupons, refunds, status, emails — and records who made it: an admin, WP-CLI, WP-Cron, or the system. Totals and addresses are diffed, so an edit reads "total $200.00 → $150.00" rather than "order updated".

PHP · WooCommerce · HPOS · Open source Docs ↗ Source ↗
MOD-06Game

Dinner Quest

A text RPG for couples deciding the week's dinners. Secret picks, enthusiasm bids, and a weighted coin flip settle each night. Solves an argument my household was having anyway.
